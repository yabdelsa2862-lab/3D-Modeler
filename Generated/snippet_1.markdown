# 3D‑Modeler

3D‑Modeler is a Python‑based toolkit for **procedural generation, manipulation, and serving of 3D models** in SCAD and STL formats.  
It’s designed for creators, engineers, and developers who want to automate 3D geometry creation and integrate models into their workflows.

## Features
- 🧩 Generate 3D models from Python scripts using parametric logic.
- 🧱 Convert and export models to `.scad` and `.stl` formats for use in OpenSCAD or slicers.
- 🌐 Optional local server (`privateserver.py`) for previewing or serving models through HTTP.
- 🖼️ Model viewer window (`privatewindow.py`) for local visualization.
- ⚙️ Integration‑ready for pipelines like Devhub or other 3D tools.
